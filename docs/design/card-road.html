《卡牌公路》设计文档

第一人称固定视角的驾驶叙事游戏。开着车穿过国道去接多年未见的女儿，用卡牌与路上的人建立联系——油门卡驱动行驶，对话卡推动关系，旅程由一段段偶遇拼成。

概述

一句话：坐在驾驶座上，穿过无尽的公路，用卡牌与路上的人建立联系。
类型：第一人称固定视角、驾驶叙事、卡牌对话、像素低保真
规模：PC 1920×1080，3–4 小时，5 个地区、20+ 个 NPC
背景故事： 10年代，路边的老旧设施与新兴城市元素并存，玩家扮演的角色需要开车驶过国道前往海边接多年未见的女儿，一路上收集各种人与事的故事
地区流程： 荒漠→半荒漠平原→城郊工业区→沿海市集→海滨

核心体验：沉浸式驾驶，信息靠场景物体传达（仪表盘、后视镜），不另加 HUD 覆盖层；有温度的连接，卡牌成为与人建立联系的语言；旅程即叙事，故事由路上一段段偶遇拼成。
参考：死亡搁浅（旅程感、连接）、Jalopy（车内视角、随机事件）、VA-11 Hall-A（左右分栏、对话驱动）、80 Days（旅途资源管理）、Lonely Mountains（低保真驾驶）
大致界面分布

1. 核心循环

行驶（30–60s）
 ├ 看仪表盘、手牌自用、车内交互
 └ 右栏提示「前方 500m 有人招手」
      ├ 不停 → 错过，继续开
      └ 停车 → 取出油门卡 → 对话（60–120s）
             ├ 拖对话卡到右栏 → 接受（卡滑入，耐心、距离变化）
             │              拒绝（弹回抖动）
             ├ 倒计时结束未出卡 → 耐心 -10
             └ 距离 <30 → 触发故事，获得奖励卡

行驶段与对话段，交替出现。停车决策窗口 5–8 秒。

2. 驾驶系统

油门卡

唯一一张"放到特定位置才生效"的卡，也是驾驶与卡牌两个系统的连接点。

位置 车辆状态
手牌区 停车
仪表盘凹槽 自动行驶，油表下降
凹槽上方 凹槽发光，准备出发

不可消耗，永远在手牌，玩家不会因缺卡被困住。放卡 = 开车、取卡 = 停车，都是主动行为，强化"我在开车"的主体感。

仪表盘

油表（F→E，<20% 红区）
速度表（行驶时 60–80 摆动）
里程表（机械数字轮）
油门槽

车内交互物

后视镜（看货物、乘客、自己脸色 = 压力）
CD 机（切 3–4 首 BGM）
点烟器（联动香烟卡）
遮阳板（可能夹照片、便条）
手套箱（收集品）

视差滚动（5 层）

天空（极慢）→ 远山（慢）→ 近景（中速）→ 道路（快）→ 路标（最快，还可以标记事件）

3. 卡牌系统

类型 消耗规则 举例
系统卡 不消耗 油门、搭载
道具卡 有次数，用完消失 香烟(10)、便当(3)
物品卡 不消耗，同一 NPC 不可重复 收音机、工具箱、名片
对话卡 不消耗，同一 NPC 不可重复 聊天气、聊路况

交互：拖到不同区域释放有不同效果（不是点击使用）

  • 拖到仪表盘区 → 自用：香烟 → 点烟器发光、压力降低；便当 → 副驾出现饭盒；工具箱 → 手套箱打开
  • 拖到右栏 → 对 NPC 打出：接受则卡滑入、表情变化；拒绝则弹回抖动、回复拒绝

初始卡组（13 张）：
油门
搭载、工具箱、收音机、褪色合照；
香烟(10)、薄荷糖(5)、便当(3)、散装酒(3)、热茶(5)；
聊天气、聊正餐、聊路况

视觉：像素卡 120×60px。道具卡牛皮纸色、系统卡墨绿、对话卡淡蓝、特殊卡动态描边，用尽 = 灰 + 斜线

4. 对话系统

主题："什么是家"的多种答案
具体数值：

属性 上限 触发 显示
耐心值 100 归零 → 对话结束 右栏耐心条
距离感 100 <30 → 触发故事结局 距离条（绿 <30、黄 <50、橙 ≥50）
倒计时 每轮 20s 超时 → 耐心 -10 数字 + 颜色

NPC 标签匹配

标签隐藏，玩家靠外观和身份推断。
例如：抽烟 → 香烟 距离 -10
好酒 → 散装酒 -10
喜甜 → 薄荷糖 -8
隐藏标签奖励观察与共情，并非数值最优解。

第一地区例子：

NPC 答案 金句 奖励（距离 <30）
老赵 留守 "我在这儿干了二十年" 《旧打火机》
背包青年 归来 "还是觉得家里好" 《桶装井水》+《家乡》
白大爷 守护 "这口井，叫等子井" 《老路》+《沙枣》（需用热茶）
老马 前行 "你在这儿。就够了" 《老马的名片》+《孜然烤馕》

5. 事件

主动停车：NPC 招手、加油站（油表低提醒）、地标观景点、岔路口（左、直、右）
被动停车：油量耗尽、压力 ≥100 强制刹车、车辆故障（爆胎、冒烟）、地区过渡
随机事件：废弃车辆、动物横穿、沙尘暴、路牌留言、收音机信号
