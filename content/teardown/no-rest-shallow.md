## 一、游戏概况

**类型**：3D 等距俯视视角 ARPG（类魂 + 类暗黑）

玩家扮演流落圣城的古老种族塞利姆的战士，围绕国王驾崩后爆发的「灾疠」瘟疫展开，在政治阴谋与瘟疫肆虐中寻求救赎，净化岛屿拯救人民。

**主要循环**：

1. 战斗探索 → 回城强化 → 战斗
2. 探索时收集资源 → 升级建筑 → 获得更多强化

## 二、关卡设计特征

### 1）美术风格

主美 Mikhail Rakhmatullin 透露核心原则是 "painting comes to life"，参考卡拉瓦乔明暗、19 世纪俄国画家，贴图全手绘（[80.lv](https://80.lv/articles/interview-inside-the-tech-and-artistic-inspirations-of-no-rest-for-the-wicked-from-moon-studios)）。

![卡拉瓦乔式强明暗与轮廓光下的场景构图](/assets/img/no-rest-shallow/art-01.jpg)

![全手绘贴图的场景细节](/assets/img/no-rest-shallow/art-02.jpg)

**设计影响**：每个场景的构图、明暗、可交互物位置都是设计者「画」出来的，设计者确定玩家在每一个位置能看见什么，这也是它使用固定镜头的前提。

### 2）垂直空间

IGN 评测：可攀爬 / 跳跃 / 平衡之处数量惊人，在等距关卡设计中不常见。大量出现爬藤蔓、爬梯子、踢梯子开捷径、走窄木板、跳浮台。

不过这样也存在问题：固定镜头下高度差与距离差难以判断，造成玩家多次误判摔死。

### 3）圣城 Sacrament 作为中央枢纽

- 地图中央唯一庇护所，每个区域都有捷径回城，初始状态下传送只能选择圣城或上一个传送点
- 城镇升级：找建筑师 Danos 升级圣城建筑，有视觉变化，开放更多货品。可购房装修、野外探索搜集建造材料：砍树挖矿
- 技术上靠 chunk 热替换实现，动态加载每个较小的区域

![圣城 Sacrament 作为地图中央的唯一庇护所](/assets/img/no-rest-shallow/sacrament.jpg)

## 三、具体拆解：开场章节全流程

关卡节奏：引入 → 加压 → 喘息 → 高压 → 归巢

### 流程详解

此时已在船上完成基础操作教学，进入大地图。基础操作包括：基础移动、跑跳、战斗、可破坏物、战利品拾取、狭窄处贴身行动。

**【节点 2】第一个存档点 whisper 附近**：首次出现时教学，藤蔓：攀爬、宝箱、火堆：烹饪、存档点：重生、钓鱼（可选）、掉落装备。

![低语点旁通往塔顶的梯子](/assets/img/no-rest-shallow/n02-ladder.jpg)

低语点旁就是梯子通往塔顶，塔顶断桥前方放置一个精英怪与宝箱，极有可能成为玩家的初次死亡体验，从而告诉玩家在低语点重生与装备耐久度的设定。因为是断桥敌人无法来到低语点一侧，所以玩家可以主动选择挑战与否。

**【节点 3】初入水手寨**

教学：潜行背刺、开阔场地遭遇战。

潜行时，镜头距离随敌人距离变小而拉近，营造紧张与压迫感。

![潜行时镜头随敌人距离拉近](/assets/img/no-rest-shallow/n03-stealth-1.jpg)

![水手寨的潜行与遭遇战区域](/assets/img/no-rest-shallow/n03-stealth-2.jpg)

探索广场发现广场左下方小区域存在怪物，玩家很可能本能后退，从而来到广场战斗，玩家自然学会拉扯与风筝，发现在开阔地区战斗更有优势。

![广场左下方的小区域与开阔战斗场地](/assets/img/no-rest-shallow/n03-plaza.jpg)

广场上方有两条支路，通过长台阶暗示玩家是通向下一区域的。

两条支路收束联通，若走破碎塔楼则在上层，若走正面则在下层，统一收束到中层，到达第二个 Whisper。

**【节点 6】大柴堆区域铁匠铺任务**

大柴堆这里的设计很舒服，整个蓝色线条以上的为二层空间，本来只能老老实实走左侧箭头处的台阶从一层到二层，但是右侧箭头这里放了一个倾斜向上的板车，让二层空间破开一道口子，从而让玩家能更方便地上到二层。

**【节点 9】Warrick the Torn（第一个 Boss）**

进圣城交任务、整备。

### 引导方式汇总（5 层）

1. **视觉**：卡拉瓦乔式强明暗与轮廓光让可交互物与出口被明显标识出来（[80.lv](https://80.lv/articles/interview-inside-the-tech-and-artistic-inspirations-of-no-rest-for-the-wicked-from-moon-studios)）
2. **地形**：固定镜头使团队能预判玩家视野，精确布置攀爬点与兴趣点，操纵规划玩家路径
3. **声音**：节点 7 用 Filmore 的声音把玩家从主干拽进铁匠铺
4. **游戏内目标**：主线任务指引 + 路牌与人物对话指引
5. **复活点锚定**：本节主线路径上三个 Whisper（节点 2 / 5 / 8）：教学时一个、主干中点一个、Boss 门口一个；火堆作为补给点（[Combat 页面](https://norestforthewicked.wiki.fextralife.com/Combat)）

### Boss：Warrick the Torn（第一个 Boss）

- 作为首个 Boss，招式有限：①冲刺 + 下劈（起手明显，有充足反应时间）②旋转刀刃（需完美时机闪避）③高前摇大范围 AOE
- 攻击「有破坏力但都有闪避 / 反击窗口」

## 四、对关卡设计的启发

1. **「玩家死后敌人不立刻刷新」是重要的关卡资源**：把死亡惩罚从「重打」变为「机会损失」，鼓励玩家在每次战斗中先杀残血，让玩家的风筝、引导怪物的每一步都有意义，所以可以设置更多开阔场地与平台，是改变玩家决策树的机制创新。
2. **垂直探索**：固定镜头与高台会导致判距困难。**教训**：垂直关卡必须给足够的判距提示（阴影、边缘高亮、固定视角下的尺寸参照物），否则挫败感会压过探索欲。
3. **枢纽镇给与玩家休息空间锚点**：单一庇护所 + 捷径网构成「出发 - 回家 - 整备」循环；商店升级有实际变化，让玩家积攒资源获取的升级得到反馈。
4. **固定镜头当作设计约束而非缺陷**：锁死摄影机让团队能「预知玩家视野」，精确布置引导 / 光照。镜头自由度很大程度上引导设计思路，越早锁定越好。

### 关联思考

- ARPG 的基因是 build 成长与战利品经济，则派发战利品的怪是可再生的资源

#### 死亡重生与玩家学习

- 大部分 ARPG 的死亡：回到几秒前的检查点，成本极低。为了让玩家学习这一个操作 / 这一关卡的通关方式
- 类魂的死亡：回到这条路的起点，让玩家规划整条路的行动与资源管理；惩罚：身上的所有货币
- 恶意不息：回到路的起点，但每杀掉一个怪物都会让这条路更轻松；惩罚：可用金币修复的装备耐久值

## 五、修改

1. **垂直落差加「两档提示」**：固定镜头下高台落差难判断。我会在落差超过摔死阈值的边缘显示落点阴影，只有危险落差才显示，保留探索风险的同时尽可能消除不公平感。成本：纯表现层，不动关卡几何。
2. **野外换皮刷新与镇子升级联动**：原作清空区域在升级后会刷出更强敌人。我会把刷新条件从「角色等级」改为与圣城建筑升级等级挂钩：升一次建筑，敌人强化一次，让变化反馈从商店货架延伸到野外，也更给玩家更多升级圣城的动力。
3. **给门锁遭遇战加可选侦查点**：原作围绕「死亡前先杀残血」做策略。我会在闸门前放一个高处瞭望位，让玩家提前看到门后敌人配置，这样「先杀谁」的规划从死后复盘提前到战前。
